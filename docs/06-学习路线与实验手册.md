# 06 · 学习路线与实验手册

## 6.1 四周路线

### 第 1 周：概念与基本操作

- 阅读 docs/01、docs/02
- 控制台建桶/上传/下载
- 安装 mcli，配置 alias
- 跑 `bucket`、`object` Demo
- 理解 9000/9001、桶/对象/前缀、SigV4

### 第 2 周：Java SDK 与常用能力

- 阅读 docs/03
- 跑 `presign`、`multipart` Demo
- 用 curl 验证预签名 GET/PUT
- 写一个小程序：上传本地目录到桶、按前缀下载
- 理解分片、ETag、Range

### 第 3 周：高级特性

- 阅读 docs/04
- 跑 `versioning`、`lock`、`lifecycle`、`policy`、`tagging` Demo
- 完成版本恢复、对象锁、生命周期、匿名策略实验
- 记录 Silo 与文档的差异

### 第 4 周：应用集成与运维

- 阅读 docs/05
- 跑 Web 文件服务，完成页面上传/下载/预签名
- 跑集成测试
- 阅读 docs/07、docs/08
- 设计一个生产方案：IAM、TLS、备份、监控、生命周期

## 6.2 实验约定

## 6.3 15 个实验

### 实验 1：服务探活与端口认知

```bat
scripts\check-server.bat
```

验收：

- S3 health 200
- S3 root 403
- Console 200
- SigV4 列桶 200

思考：为什么 9001 返回 HTML，9000 返回 XML？

### 实验 2：控制台建桶与上传

1. 打开 `http://127.0.0.1:9001`，登录 `minioadmin/minioadmin`。
2. 创建桶 `lab-console`。
3. 上传一个文本文件。
4. 查看对象元数据、预览、下载。
5. 尝试删除非空桶，观察提示。

验收：能在控制台完成创建/上传/下载/删除。

### 实验 3：mcli alias 与基本命令

安装 mcli 后：

```bat
mcli alias set silo http://127.0.0.1:9000 minioadmin minioadmin
mcli mb silo/lab-mcli
mcli cp .\README.md silo/lab-mcli/docs/README.md
mcli ls -r silo/lab-mcli
mcli stat silo/lab-mcli/docs/README.md
mcli cat silo/lab-mcli/docs/README.md
mcli rm --recursive --force silo/lab-mcli
mcli rb silo/lab-mcli
```

验收：每个命令成功；理解 `silo/bucket/key` 路径。

### 实验 4：BucketDemo 与非空保护

```bat
scripts\demo.bat bucket
```

验收：输出 `BucketNotEmpty / HTTP 409`，清空后删除成功。

### 实验 5：ObjectDemo 与 Range/复制

```bat
scripts\demo.bat object --keep=true
```

验收：stat 元数据、GET 内容、Range 前 5 字节、copy、前缀列举均成功。用控制台观察 `learn-object` 桶，完成后清理。

### 实验 6：预签名 GET

```bat
scripts\demo.bat presign --keep=true
```

验收：预签名 GET 200，内容正确；8 天有效期抛 `IllegalArgumentException`。

手动验证：

```bat
curl -s -o NUL -w "%{http_code}" "<presigned-get-url>"
```

注意 URL 含 `&`，cmd 中整体加双引号。

### 实验 7：预签名 PUT

1. 用 Web 页面或 SDK 生成 PUT URL（`presign` Demo 会打印/生成）。
2. 用 curl 上传：

```bat
curl -X PUT --data-binary "@README.md" "<presigned-put-url>"
```

3. 用 `mcli stat` 或 Demo 的 stat 验证大小。

验收：PUT 200，对象大小正确；理解浏览器直接 PUT 的 CORS 限制。

### 实验 8：版本控制与删除标记

```bat
scripts\demo.bat versioning --keep=true
```

验收：

- 两个 versionId
- 删除后出现 Delete Marker
- 按 versionId 读取旧内容
- SUSPENDED 写入 `versionId=null`

用 `mcli ls --versions -r silo/learn-version` 观察，完成后清理。

### 实验 9：对象锁

```bat
scripts\demo.bat lock --keep=true
```

验收：

- 对象锁桶自动版本化
- 默认 GOVERNANCE
- legal hold 开关
- 无 bypass 删除被拒（Silo 返回 `InvalidRequest`/400）
- bypass 删除成功

思考：GOVERNANCE 与 COMPLIANCE 的区别？为什么测试只用 GOVERNANCE？

### 实验 10：生命周期

### 实验 11：分片上传

### 实验 12：匿名只读策略

### 实验 13：SSE-C 与 HTTPS

第一步，HTTP 下观察安全拦截：

```bat
scripts\demo.bat ssec
```

验收：SDK 抛 `IllegalArgumentException`，提示必须使用安全连接。

第二步，按 [08-SSE-C-HTTPS实验](08-SSE-C-HTTPS实验.md) 启动临时 TLS 实例，运行：

```bat
java -Djavax.net.ssl.trustStore=target\tls\truststore.p12 ^
     -Djavax.net.ssl.trustStorePassword=changeit ^
     -jar target\minio-learn-0.0.1-SNAPSHOT.jar ^
     --demo=ssec --learn.minio.endpoint=https://127.0.0.1:9443
```

验收：加密写入、解密读取、stat 成功；无 key 读取 400。

## 6.4 自测题

1. 为什么预签名 URL 不需要把密钥发给客户端？
2. 版本化桶里“删除”一个对象，实际发生了什么？
3. GOVERNANCE 与 COMPLIANCE 的删除行为差异？
4. 为什么 SSE-C 必须 HTTPS？
5. 分片上传的 ETag 为什么不是整个文件的 MD5？
6. 生命周期配置成功后为什么对象没有立刻消失？
7. 匿名只读策略与预签名 URL 的权限模型有何不同？
8. 为什么对象锁必须在建桶时开启？
9. 版本化桶如何彻底删除？
10. 生产环境为什么不能用 root 凭据？
